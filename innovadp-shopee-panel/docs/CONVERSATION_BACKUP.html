InnovadpStore · Painel Shopee

Resumo de configurações, rotas e passos importantes

Visão Geral

  • Stack: Next.js 14 (App Router), TypeScript, Tailwind.
  • Rotas API para Shopee (OAuth, Push, Métricas, Scan).
  • PWA: manifest + service worker (instalável no celular/desktop).
  • Scanner: Html5Qrcode priorizando câmera traseira.

Rotas Principais

  • GET /api/today — métricas do dia (pedidos READY_TO_SHIP, faturamento, perHour)
  • GET /api/scan?code=ORDER_SN — detalhes do pedido para picking
  • GET /api/shopee/push — saúde do webhook (retorna { ok: true })
  • POST /api/shopee/push — Mecanismo de Empurrar (assinado via HMAC)
  • GET /api/shopee/oauth/start?target=shop — inicia OAuth
  • GET /api/shopee/oauth/callback — troca code por tokens

Varioveis de Ambiente (produ??uo)

Definir em Vercel → Project → Settings → Environment Variables (Production/Preview/Development):

  • SHOPEE_PARTNER_ID, SHOPEE_PARTNER_KEY, SHOPEE_SHOP_ID
  • SHOPEE_ACCESS_TOKEN, SHOPEE_REFRESH_TOKEN
  • SHOPEE_PUSH_PARTNER_KEY (Live Push Key)
  • SHOPEE_API_HOST, SHOPEE_API_URL (opcional, mantenha o padr??o)
  • SCAN_ORDER_STATUSES, SCAN_ORDER_LOOKBACK_DAYS, SHOPEE_MAX_ORDER_PAGES, TODAY_STATS_CACHE_MS (opcionais)

Repita os valores para Production/Preview/Development e, se usar a CLI, rode vercel env pull .env.local para sincronizar.

OAuth (gerar tokens)

  • Início: /api/shopee/oauth/start?target=shop
  • Após autorizar, o callback responde com access_token e refresh_token.
  • Atualize as variáveis no Vercel e redeploy.
  • Escopos recomendados: Order e Product.

Redirect URL Domain (Shopee): usar o domínio estável do projeto (não o de deployment).

Mecanismo de Push

  • URL: https://SEU-DOMINIO/api/shopee/push
  • Área de serviço: Brasil (gru1)
  • Live Push Partner Key → SHOPEE_PUSH_PARTNER_KEY (Vercel)

O webhook responde success no handshake e valida a assinatura HMAC para eventos reais.

PWA (instalar como app)

  • Android (Chrome/Edge): menu → “Instalar app”.
  • iOS (Safari): compartilhar → “Adicionar à Tela de Início”.
  • Desktop (Chrome/Edge): Ícone “Instalar” na barra de endereço.

Arquivos: public/manifest.webmanifest e public/sw.js. Componente: components/RegisterSW.tsx.

Scanner (Câmera Traseira)

  • Implementado com Html5Qrcode, prioriza “rear/environment” por label.
  • Fallback: { facingMode: { exact: 'environment' } }.
  • Arquivo: components/Scanner.tsx.

Notas de Produção

  • Desative “IP Address Whitelist” na Shopee (ou use egress IP fixo) para evitar 403/invalid token.
  • Paginação de pedidos via cursor (até TODAY_MAX_ORDERS).
  • O backend tenta renovar o token automaticamente (200 com erro ou erro HTTP).
